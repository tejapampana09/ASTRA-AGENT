# ASTRA 2.0 — Evaluation Suite

## Benchmark Metrics

- **Task Completion Rate**: Percentage of tasks achieving empirical verification.
- **Test Pass Rate**: Proportion of repository tests passing after agent modifications.
- **Regression Rate**: Ensures existing passing tests are not broken by fixes.
- **Mean Iterations**: Average cycle count required to reach resolution.
- **Human Intervention Rate**: Number of required approval requests per task.
